# MINIX ER939-AI / ER939-AI Pro

Last updated: **2026-08-24**

The MINIX ER939 family is a system-level implementation of the already tracked **AMD Ryzen AI Max+ 395 / Radeon 8060S (Strix Halo)** compute platform. It should therefore be deduplicated with other Strix Halo systems when comparing silicon performance.

## Why it matters

Both current ER939 variants expose **128 GB LPDDR5X-8000 unified memory**, which is the main reason they are relevant to local LLM inference. The **ER939-AI Pro** is the more interesting distributed-inference node because it adds **dual 10GbE**, while the base ER939-AI exposes a single 2.5GbE port.

## ER939-AI

- AMD Ryzen AI Max+ 395, 16 cores / 32 threads
- Radeon 8060S
- 50 TOPS NPU / up to 126 TOPS vendor total-AI figure
- 128 GB LPDDR5X-8000 unified memory
- 2 TB PCIe 4.0 NVMe SSD
- second M.2 PCIe 4.0 x4 storage slot
- 2.5GbE, Wi-Fi 7, Bluetooth 5.4
- dual USB4 40Gb/s
- 240 W power adapter
- Windows 11 Pro

## LLM assessment

The ER939 family does not create a new performance class relative to other Ryzen AI Max+ 395 systems. Its value is determined mainly by:

- delivered price;
- whether the 128 GB configuration is actually in stock;
- sustained cooling at high package power;
- networking, where the Pro's dual 10GbE is materially stronger for distributed inference;
- Linux/ROCm/Vulkan runtime behavior;
- whole-system wall power under sustained decode.

No normalized independent LLM benchmark is recorded for these exact MINIX chassis yet. Do not transfer another Strix Halo vendor's chassis-specific benchmark to MINIX without labeling it as platform-level evidence.
